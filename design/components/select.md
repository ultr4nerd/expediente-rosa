# Select

## Purpose

One option out of 5 to 15. With 2-4 options use visible radio buttons; with more than 15, search.

## Tokens

Same as Input: `color.surface-raised`, border `color.input`, `spacing.control`, text `type.body`.
Highlighted option `color.highlight` / `color.on-highlight`.
