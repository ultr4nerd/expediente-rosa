# Design decisions

## 2026-11-21: initial system

- Brand pink `#b7426c` and plum `#6a2b51` measured from eiraac.org CSS (provisional).
- Own warm neutrals; green/amber/red for synced/pending/conflict; dark neutral for offline.
- Focus in plum (not pink) to distinguish it from the primary action.
- Atkinson Hyperlegible Next (body) + Montserrat (headings), OFL, bundled locally.
- Light mode only. shadcn/ui with variables generated by `design build` (`design.json` `shadcn`).
