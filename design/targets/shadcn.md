# shadcn/ui

shadcn's theme variables (`--primary`, `--background`, ...) are generated by `design build` from
`shadcn.vars` in `design.json`. Never edit them in `globals.css`: change a token or the mapping.

## Wiring

- `src/styles/globals.css`: `@import "tailwindcss"`, `tw-animate-css`, the `@fontsource-variable` fonts,
  then `design/tokens.css`, and shadcn's `@theme inline` block. No custom `:root` or `.dark` blocks.
- The same `@theme inline` registers the custom roles (`bg-success-subtle`, `text-on-warning-subtle`,
  `bg-autofill`, `bg-offline`...) so they get Tailwind utilities.
- `components.json` `aliases.ui`: `@/components/ui` (same as `shadcn.import`); files in `src/components/ui`.
- Alias `@` → `src` in `vite.config.ts` and `tsconfig.json` (`paths`).
- Light mode only. `next-themes` was removed from sonner.

## Verify

- `pnpm design check` and `pnpm build`.
- After `shadcn add` or an update: review the diff of `src/components/ui/` and note changes here.
  The CLI sometimes writes `from "cn"`: fix it to `@/lib/utils`.
