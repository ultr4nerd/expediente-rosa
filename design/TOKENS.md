# Design tokens

_Generated by `design build` from `design/tokens.json`. Do not edit by hand._

Use names, never values. CSS `var(--color-surface)`, TS `tokens['color.surface']`; Tailwind utilities use the same names (`p-md`, `rounded-card`; colors through the shadcn roles below); `type.*` are utility classes.
`primitive.*` is never used in code. `(provisional)` may still change. "on:" lists checked backgrounds with contrast ratios.

## spacing

- `spacing.xs` 4px — Icon with its label; minimal gaps
- `spacing.sm` 8px — Between related elements; chip padding
- `spacing.md` 16px — Card and control padding; space between fields
- `spacing.lg` 24px — Between groups within a section
- `spacing.xl` 32px — Between sections of a screen
- `spacing.2xl` 48px — Margins of empty and home screens
- `spacing.control` 44px — Minimum height of buttons, inputs and selects (click target)
- `spacing.control-lg` 52px — Height of a form's primary action (Guardar, Registrar)
